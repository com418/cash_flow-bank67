Security built into the experience.

Customer authentication is handled through Firebase Authentication while account records are stored in Firestore under security rules.

Authentication

Customer credentials are handled by Firebase Authentication. Passwords are not written into customer Firestore documents.

Firestore Rules

Customer records are protected by Firestore security rules that determine which authenticated users can access records.

Account Review

New customer records begin in a pending state and can remain inaccessible until an authorized administrator reviews them.
